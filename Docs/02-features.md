# Features

This document is a condensed index of every feature. Full 20-section Feature Design Documents exist separately per feature (dashboard, budget-search, ai-explain, charts-visualization, budget-comparison, bookmarks, profile-settings, feedback, budget-simulator) and should be used as the source of truth when building each one.

## 2. Dashboard — *Must Have*
Landing point. Shows a default budget snapshot, sector selector, bookmarks shortcut, and an AI Explain teaser — all within 5 seconds of load.
- Key data: country, year, department/category breakdown, top sectors
- Key screens: Dashboard

## 3. Budget Search — *Must Have*
Fast, fuzzy search across budget categories/departments, filterable by country and year. Links directly into Charts and AI Explain.
- Key data: country, year, category, allocated amount
- Key screens: Search, Results List, Budget Detail

## 4. AI Explain — *Must Have*
One-line-to-a-few-sentences plain-language explanation of a budget figure, generated by Gemini, grounded in real data, streamed and cached.
- Key data: budget context (category, amount, prior year, growth %)
- Key screens: inline AI Explain card, optional follow-up chat

## 5. Charts & Visualization — *Must Have*
Interactive pie/bar/line charts showing budget proportion and trend, with accessible text alternatives and hover/tap detail.
- Key data: category, amount, prior year amount, growth %
- Key screens: embedded chart card, expanded chart modal

## 6. Country / Year Comparison — *Must Have*
Compare two years (or countries) side by side, with AI-generated summary of what changed and why.
- Key data: two budget datasets (country/year pairs), growth %, inflation-adjusted values
- Key screens: Compare page, Comparison Result, Share Dialog

## 7. Budget Reallocation Simulator — *Must Have (added during scoping)*
Drag a slider to increase/decrease a sector's funding and see, in real time, which other sectors are affected (zero-sum redistribution), with an optional AI tradeoff explanation.
- Key data: baseline budget per sector, adjustable min/max range
- Key screens: Simulator panel on Budget Detail

## 8. Bookmarks — *Should Have*
Save a budget item or comparison for quick return access. One-tap toggle, synced across devices.
- Key data: user_id, budget_id, timestamp
- Key screens: Bookmark toggle (inline), Bookmarks list

## 9. Profile & Settings — *Should Have*
Edit name/country/profession, toggle dark mode, log out. Instant, persisted preferences.
- Key data: name, country, profession, theme preference
- Key screens: Profile, Settings

## 10. Feedback — *Could Have*
Lightweight modal accessible from anywhere to report bugs, confusion, or suggestions.
- Key data: category, message, page context
- Key screens: Feedback modal

## 11. Profile 3D Visualizer — *Could Have*
Not yet speced in detail. Placeholder for a richer, possibly 3D personal budget-impact visualization tied to the user's profile.

## 12. Community — *Could Have*
Not yet speced. Placeholder for user-to-user discussion around budgets (comments, shared simulations, etc.).

## 13. Voice Assistant — *Could Have*
Not yet speced. Placeholder for voice-driven Q&A layered on top of AI Explain.

## 14. Won't Have (v1)
- Multiplayer / chat
- Marketplace
