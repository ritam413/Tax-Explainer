Streaming AI Explanations via Server-Sent Events (SSE)

Clicking "Explain with AI" on sector rows to trigger token-by-token plain-language translation.

Gemini 2.0 Flash Lite Integration
Custom grounded prompts strictly enforced with JSON/markdown schemas to prevent AI hallucinations.
Server-Sent Events (SSE) Protocol
HTTP response streaming (`ReadableStream`) outputting `data: {"text":"..."}` chunks token-by-token without blocking HTTP threads.
Strict Usage Controls
Gemini API is never called automatically on page load; triggered strictly on user explicit CTA click to conserve quota.
LIVE SSE STREAMING CODE SIPPET
const encoder = new TextEncoder();
const stream = new ReadableStream({
  async start(controller) {
    for await (const chunk of result.stream) {
      controller.enqueue(
        encoder.encode(`data: ${JSON.stringify({ text: chunk.text() })}\n\n`)
      );
    }
    controller.enqueue(encoder.encode('data: [DONE]\n\n'));
    controller.close();
  }
});
return new Response(stream, { headers: { 'Content-Type': 'text/event-stream' } });

Zero-Sum Fiscal Simulator & Hamilton Rounding

Switching to `/simulator`: Reallocating sector budgets with mathematical quota conservation.

Zero-Sum Redistribution Equation
Increasing one sector $\Delta S_k > 0$ forces proportional offset across unlocked sectors: $\Delta S_i = -\Delta S_k \cdot \frac{S_i}{\sum_{j \in Unlocked} S_j}$, ensuring $\sum \Delta S = 0$.
Hamilton Largest-Remainder Method
Eliminates floating-point currency rounding errors during live 60fps slider drags by allocating remainder fractions to largest decimal remainders.
AI Policy Trade-off Stream
Evaluates macroeconomic consequences of hypothetical allocations on GDP growth, inflation, and employment.
🧠 Moderate Tech Explanation (Spoken at 2:55): "For the simulator engine in `lib/utils/simulator.ts`, I wrote a zero-sum algorithm using the Hamilton Largest-Remainder method. When you adjust a slider, it redistributes the delta across unlocked sectors while guaranteeing zero total budget drift."

Inflation-Adjusted YoY Comparison Engine

Switching to `/compare`: Calculating real vs nominal spending deltas across multi-year budgets.

  • Full Outer Join Comparison Algorithm
    `compareBudgets(datasetA, datasetB, inflationRate)` handles new, discontinued, increased, and decreased sector items seamlessly.
  • Real vs Nominal Delta Formula
    Real Delta = $\text{Amount}_B - (\text{Amount}_A \times (1 + \text{Inflation}))$, preventing misleading growth figures during inflationary cycles.
